# 🍅 Pomodoro Timer

A simple and interactive productivity timer designed to improve focus and time management using the Pomodoro Technique.

## 📌 Project Overview

The Pomodoro Timer is a web-based productivity application that helps users divide their work into focused sessions followed by short and long breaks. It encourages better time management, reduces distractions, and promotes consistent productivity.

## ✨ Features

- **Focus Session:** 25-minute focused work timer.
- **Short Break:** 5-minute break after a focus session.
- **Long Break:** 15-minute break after every four completed focus sessions.
- **Start / Pause / Resume:** Control the countdown timer.
- **Reset Timer:** Reset the current session.
- **Automatic Session Switching:** Switch between focus and break sessions automatically.
- **Session Counter:** Track completed focus sessions.
- **Sound Notification:** Audio alert when a session ends.

## 🛠️ Technologies Used

- HTML5 – Application structure.
- CSS3 – Styling and responsive layout.
- JavaScript – Timer functionality and session management.

## 🚀 Getting Started

### Prerequisites

- Visual Studio Code
- A modern web browser
- Live Server extension for VS Code

### Installation

1. Clone the repository:

```bash
git clone https://github.com/nayanaa006/pomodoro.git
```

2. Navigate to the project directory:

```bash
cd pomodoro
```

3. Open the folder in Visual Studio Code.

4. Install the Live Server extension.

5. Right-click `index.html` and select **Open with Live Server**.
